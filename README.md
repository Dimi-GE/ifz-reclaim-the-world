# Reclaim The World

A mod for Infection Free Zone: settlements left behind keep producing, and their surplus follows the convoy.

Website: https://dimi-ge.github.io/ifz-reclaim-the-world/ (roadmap and board)
Bugs and ideas: this repository's Issues. The website's board reads them.
The mod: in development, no public build yet. Downloads: Nexus Mods.
