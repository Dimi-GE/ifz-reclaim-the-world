Reclaim The World

Infection Free Zone · BepInEx 5 mod

Settlements left behind keep the production pipeline. Their surplus follows the convoy to the next settlement.

Roadmap

One complete mechanic per release. No dates.

  1. GroundworkDone

    Game code mapped, build pipeline in place, a data plugin reading the settlement live.

  2. Release 1 · Live panelIn progress

    First public test build.

    • An in-game panel for the current settlement, in the game's own style (F8)
    • Production by building: workers, recipes, inputs and outputs
    • Balance per resource: produced, used, net, stock
    • Select a resource to see what makes it and what uses it
    • Install guide
  3. Release 2 · Supply linesPlanned

    The core of the mod.

    • When the convoy leaves, the settlement's full state is saved
    • Every day, each old settlement's surplus arrives at the current one
    • Shortfalls follow the game's own rules: the current settlement covers the gap
    • Page through the settlements in the panel
  4. Release 3 · Settlement overviewPlanned

    A larger view on the pause screen: the settlements on the globe, click one for its stats. If the globe can't be reused, a list with richer stats instead.

Everything beyond this lives on the board as ideas: remote management, specialised settlements, trading.
